**Baselines To Steal**
Use these across domains: random action ordering; greedy geometric clearance; one-step “best immediate progress”; BFS/A*/weighted A* over simulator calls; MCTS/UCT; policy-guided tree search; PDDLStream/FastDownward for symbolic domains; VPG/VFT-style learned Q or learned dynamics; entropy/area-reduction for shelf search.

**Top 3**
1. **VFT object retrieval from clutter**: best code-backed match to “rank pushes + search + verifier.” Start here.
2. **LAX-RAY-style shelf search**: cleanest 2D/SE(2) push-only benchmark with real setup moves; reimplement if repo is missing.
3. **Boxoban/Sokoban abstraction**: fastest way to stress-test learned ordering on huge irreversible push puzzles; not physics, but perfect for search-cost curves.

If you want the most robotics-real version, swap #3 for **Ravens `sweeping-piles` plus a custom push-to-clear task**.
